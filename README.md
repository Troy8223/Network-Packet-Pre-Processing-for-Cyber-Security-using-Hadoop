# Network-Packet-Pre-Processing-for-Cyber-Security-using-Hadoop

Hadoop Streaming prototype that parses PCAP files and aggregates packet rows for cybersecurity feature extraction.

The intended next step is a versioned, windowed feature stage for an IoT ML-IDS. See [IMPROVEMENT_PLAN.md](IMPROVEMENT_PLAN.md).
